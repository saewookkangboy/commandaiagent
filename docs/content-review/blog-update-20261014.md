# 블로그 5편 검토와 도서 소개 시리즈 3편 추가 결과

기존 SEO·GEO·AIEO 실무 가이드 5편을 공식 출처 기준으로 점검하고, 확인된 모호함과 과장을 수정했습니다. 첨부된 『AI Agent를 지휘하는 마케터』 최종 내지 PDF를 중심으로 도서 소개 시리즈 3편을 추가했습니다. 총 8편에 각각 카툰·한국어 손글씨 대표 이미지를 적용했습니다.

**검토 기준일: 2026년 10월 14일.** 원고는 AI를 활용한 Command Marketing 편집 콘텐츠입니다. 도서 소개는 저자의 직접 집필 블로그가 아니라 제공된 PDF의 요약이며, 가상 사례와 실행 체크는 편집 응용으로 구분했습니다.

## 기존 5편에서 수정한 부분

### 1. SEO·GEO·AIEO, AI 검색 시대 콘텐츠 전략은 무엇이 달라져야 할까?

AIEO는 이 사이트에서 **AI Engine Optimization**으로 정의하는 편집상 용어이며, **AEO(Answer Engine Optimization)**와 구분하도록 보완했습니다. Google Search에서 생성형 검색 최적화도 기존 SEO 원칙의 적용이라는 점을 반영했습니다.

GEO 논문의 ‘최대 40%’는 해당 벤치마크의 가시성 결과이며 실제 사이트의 인용·유입·매출 상승률이 아니라는 범위를 명시했습니다. Googlebot·Google-Extended, OAI-SearchBot·GPTBot의 목적과 제어 차이도 보완했습니다.

### 2. AI 답변에 인용되기 쉬운 콘텐츠 구조: GEO 실무 가이드

FAQ 본문은 독자의 질문에 답하는 장치이지 FAQPage 마크업으로 AI 인용을 확보하는 장치가 아님을 명확히 했습니다. 공식 변경 이력의 FAQ 리치 결과 종료 정책을 반영했습니다. GEO 연구의 초록으로 재확인하지 못한 세부 실험 설명은 제거하고, 확인된 벤치마크·도메인별 차이·가시성 범위만 남겼습니다.

Search Console 생성형 AI 보고서의 노출은 답변 인용 횟수나 매출이 아니라, 지원되는 생성형 검색 기능에서 사이트 링크가 표시된 횟수라는 점을 보완했습니다.

### 3. AI 검색 기술 SEO 체크리스트: 초기 HTML부터 크롤러·스키마까지

검색용 크롤링, 학습·그라운딩 활용 제어, Search Console의 생성형 기능 포함 설정을 구분했습니다. 보고서가 제공하는 노출 지표와 충분한 노출이 없을 때 보고서가 표시되지 않을 수 있다는 조건을 보완했습니다. FAQ 정책의 참고문헌은 현재 공식 변경 이력으로 교체했습니다.

초기 HTML, canonical, sitemap, robots와 noindex의 차이, Article·BreadcrumbList의 본문 일치 원칙은 유지했습니다. 크롤러 접근이나 마크업이 실제 색인·인용·사업 성과를 보장하지 않는다고 명확히 했습니다.

### 4. SEO·GEO 콘텐츠 Agent, R-G-C-T-O-R로 안전하게 운영하는 법

검색용 OAI-SearchBot과 학습용 GPTBot이 독립적으로 제어된다는 설명을 보완했습니다. llms.txt의 비효과 설명은 **Google Search의 생성형 기능**으로 한정해 다른 AI 서비스까지 동일하게 단정하지 않도록 수정했습니다.

사실성·브랜드·권리·개인정보 검수와 사람의 최종 승인 원칙은 유지했습니다. 생성형 검색 노출 지표만으로 클릭·전환·매출이나 인용 품질을 단정하지 않도록 추가했습니다.

### 5. SEO·GEO·AIEO 성과 측정: 클릭·인용·전환을 분리하는 방법

Search Console 생성형 AI 보고서의 실제 지표가 AI Overviews·AI Mode의 사이트 링크 **노출**임을 명시했습니다. 보고서 미표시 조건에 충분한 노출 부족과 생성형 기능 제외 설정을 반영했습니다.

고정 질문 표본의 수동 인용 관찰은 전체 이용자의 노출률이나 매출 인과효과가 아니라는 기존 한계를 유지했습니다. 검색 접근 허용·llms.txt·구조화 데이터가 AI 인용이나 트래픽 약속이 아님을 정리했습니다.

## PDF 중심 책 소개 시리즈 3편

### 1편 — AI를 쓰는 마케터에서 지휘하는 마케터로: Agent와 거버넌스

**독자 질문:** AI에게 일을 맡기려면 무엇을 먼저 결정해야 하는가?

Prologue와 Part 1·2를 바탕으로 Chat AI와 Agent AI의 차이, 업무 위임 판단, 개인정보·브랜드 거버넌스, Human-in-the-loop과 사람의 최종 책임을 소개합니다. 배송 지연 불만을 캠페인 개선으로 연결하는 장면은 도서 원문 사례가 아닌 편집 응용으로 표시했습니다.

**주요 도서 근거:** pp.4–7, 11–16, 47–52, 66–71, 79–83. 각 관련 문장 옆에도 페이지를 표시했습니다.

### 2편 — R-G-C-T-O-R로 설계하는 AI 마케팅 업무 지시서

**독자 질문:** 프롬프트를 팀이 재사용하는 업무 지시서로 바꾸려면 어떻게 해야 하는가?

Part 3·5를 중심으로 Role·Goal·Context·Tool·Output·Review의 여섯 요소, Workflow와 승인 상태, 콘텐츠 기획·SEO·랜딩페이지 QA를 소개합니다. 가상 무료 데모 캠페인은 편집 응용입니다. 실제 랜딩의 구매 앵커는 `/#purchase`로 연결했습니다.

**주요 도서 근거:** pp.100–123, 171–177, 185–196.

### 3편 — 21일 훈련으로 만드는 AI 마케팅 운영 루프

**독자 질문:** 작은 반복 업무부터 AI 마케팅 운영 루프를 만들려면 무엇을 연습해야 하는가?

Part 6·7을 중심으로 광고·CRM·리포팅·실험을 기록과 사람의 승인으로 연결합니다. 책의 실제 3주 플랜을 관찰과 분해, 지시와 생성, 검수와 시스템화로 소개합니다. 월간 사용성·품질·안전성·학습성 점검도 포함합니다. 주간 리포트 사례는 편집 응용이며 21일 안에 성과나 완성을 보장하지 않습니다.

**주요 도서 근거:** pp.215–219, 244–249, 253–260, 273–280, 286–294, 303–308.

## 썸네일 8종과 사이트 반영

청록·아이보리·머스터드 색상과 잉크 스케치 카툰, 한국어 붓펜 손글씨를 사용했습니다. 등장인물은 가상의 마케터이며 저자의 초상화가 아닙니다. 각 글의 주제에 맞춘 별도 이미지입니다. 용어 썸네일의 AEO 오기는 한 차례 수정하여 **AIEO**로 반영했습니다.

- 원본 생성 이미지: 2560×1440.
- 사이트용: 1200×675 WebP, 약 90–173KiB.
- 공유·재사용용: 1200×675 JPG, 약 141–239KiB.
- 이미지 전체를 보존해 축소했으며 손글씨 영역을 자르지 않았습니다.
- 카드·글 상단·alt·OG·Twitter Card·BlogPosting 이미지에 글별 파일을 연결했습니다.
- 블로그 목록은 책 소개 3편과 실무 가이드 5편을 분리하고 시리즈 목차·이전·다음 링크를 추가했습니다.
- 홈의 블로그 영역, sitemap 10개 URL, 경로 선언, llms.txt도 갱신했습니다.

## 확인된 검증 결과

`python3 scripts/check_blog.py`가 통과했습니다. 총 8편의 제목·설명·canonical·OG/Twitter 이미지·JSON-LD·출처 참조·로컬 링크·앵커·시리즈 연결·사이트맵 10개 URL을 검사했습니다.

로컬과 공개 미리보기에서 목록·신규 글·WebP·경로 선언은 HTTP 200, 존재하지 않는 글은 실제 HTTP 404를 확인했습니다. 미리보기는 `X-Robots-Tag: noindex, nofollow`를 응답합니다.

390·768·1440px 너비에서 목록과 시리즈 2편의 이미지 로딩, 가로 넘침 없음, 시리즈 탐색 상태, 실행 오류 없음을 확인했습니다. 별도 읽기 전용 통합 검토에서도 구체적인 결함을 발견하지 못했습니다. 과거 Lighthouse 점수를 이번 버전의 점수로 사용하지 않았습니다.

## 확인·수정할 때

**[블로그 미리보기](https://4174-iq7i91rqtjypnfww5tldo-89d7f164.sg2.manus.computer/blog)**에서 총 8편을 볼 수 있습니다. 이는 임시 검토용 주소이며 운영 사이트가 아닙니다.

원고는 저장소의 `content/blog/<slug>.md`, 제목·설명·관련 글·이미지 정보는 `content/blog/posts.json`에서 편집합니다. 이후 아래 명령으로 정적 파일과 검색 보조 문서를 재생성합니다.

```sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/build_blog.py
python3 scripts/check_blog.py
```

편집 원고와 생성 HTML을 함께 커밋해야 합니다. Vercel은 기존처럼 `dist`를 배포하므로 Python은 운영 서버 의존성이 아닙니다.

**GitHub 작업 브랜치:** `feat/book-series-cartoon-thumbnails`. 최초 랜딩·5편은 main에 병합된 상태지만, 이번 후속 확장과 운영 도메인 배포는 별도입니다. Vercel 연결이 이전 단계에서 승인되지 않았으므로 `book.allrounder.im`에 새 글이 반영되었다고 주장하지 않습니다. 후속 변경은 [PR #2](https://github.com/saewookkangboy/commandaiagent/pull/2)에 커밋·푸시했습니다. PR은 OPEN 상태이며 main 병합·운영 배포는 아직 하지 않았습니다.

원본 PDF와 전체 도서 추출 텍스트는 저장소·배포 산출물·전달 패키지에 넣지 않았습니다. 특정 사이트의 Search Console 실측, 실제 색인, AI 서비스 인용, 전환·매출 효과는 이번 콘텐츠 검토의 검증 대상이 아니며 보장되지 않습니다.
