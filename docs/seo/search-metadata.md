# 블로그 8편 검색 메타데이터 최적화

실무 가이드 5편은 비교·작성·기술·운영·측정 의도를, 도서 시리즈 3편은 위임·업무 지시서·21일 훈련 의도를 구분한다. 기존 본문 H1·URL·canonical·출처·썸네일은 유지하고, 검색 제목과 설명, 보이는 요약·주제 라벨을 최적화했다.

## 구현과 검증

8편에 고유한 title·description·OG·Twitter·keywords·article:section·article:tag를 정적 생성한다. BlogPosting은 화면 H1을 headline으로 유지하고, alternativeHeadline·abstract·keywords·about을 실제 보이는 내용과 일치시킨다. 요약과 주제는 숨기지 않고 독자에게 제공하며 빈 태그 페이지를 만들지 않는다.

scripts/check_blog.py에서 8편 제목·설명·키워드·요약·JSON-LD의 일치, 내부 링크·이미지·시리즈 탐색·10개 사이트맵 URL·원본 PDF 비공개를 검사한다. 원고 Markdown과 기존 크롤러 정책은 변경하지 않는다.

색인 요청·사이트맵 제출은 별개 작업이다. Google Search Console과 Naver 서치어드바이저의 접근 제한 때문에 이번 변경만으로 색인 완료·검색 노출 증가를 주장하지 않는다.
