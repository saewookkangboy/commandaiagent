# AI Agent를 지휘하는 마케터

> 박충효 저 『AI Agent를 지휘하는 마케터』의 공식 도서 소개 사이트입니다. AI 에이전트 마케팅, R-G-C-T-O-R 업무 지시서, 21일 훈련과 SEO·GEO·AIEO 편집 콘텐츠를 제공합니다. 공식 브랜드는 TROE이며 주 언어는 한국어(ko-KR)입니다.

정규 사이트 주소: https://book.allrounder.im/

## 도서의 핵심 정보

『AI Agent를 지휘하는 마케터』는 AI에게 일을 맡기고, 필요한 맥락을 제공하고, 결과를 검수해 반복 가능한 마케팅 업무 시스템으로 만드는 방법을 다루는 320쪽 실무 가이드입니다. 마케터가 목표와 판단 기준을 정하고 Agent가 리서치·초안·반복 실행을 보조하며 사람이 승인과 최종 책임을 맡습니다.

- Command Marketing: 질문하는 마케터에서 지휘하는 마케터로 전환하는 운영 관점
- R-G-C-T-O-R: Role, Goal, Context, Tool, Output, Review로 구성하는 업무 지시서
- AI 활용 성숙도: 체험형 사용자에서 Agent 운영자와 커맨드 마케터로 이동하는 5단계
- 도서 7개 파트: AI Agent 리터러시, 거버넌스, 마케팅 OS, 리서치·전략, 콘텐츠·크리에이티브, 광고·CRM·성과분석, 운영 매뉴얼
- 21일 훈련: 업무 분해, 지시서·검수 기준 설계, 반복 가능한 운영 루프 구축

책 소개 시리즈 3편은 제공 PDF를 요약한 편집 글이며 각 글에 도서 페이지 근거가 있습니다. 원본 PDF는 공개하지 않습니다. 실무 가이드 5편은 공개 출처 기반 응용 콘텐츠로 도서 발췌나 저자의 직접 발언이 아닙니다. 두 유형 모두 AI 초안을 활용한 Command Marketing 편집 콘텐츠이며 저자가 직접 집필한 블로그 글로 해석하지 않습니다. 가상 사례·체크리스트 등은 편집 응용으로 구분합니다.

AIEO는 사이트 편집상 AI Engine Optimization으로 정의합니다. 보편적으로 합의된 독립 표준이나 검색엔진 공식 순위 요소로 제시하지 않습니다. 인용할 때는 해당 canonical 페이지의 본문, 기준일, 도서 페이지 근거와 공개 출처를 함께 확인하세요. 블로그의 책 소개는 도서 전체를 대체하지 않으며 실제 캠페인 성과·수익·검색 노출·AI 인용을 보장하지 않습니다.
