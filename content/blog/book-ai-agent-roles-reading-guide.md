# 책 속 AI Agent 17가지 역할: 내 업무에 맞게 읽는 가이드

AI Agent 역할별 특징을 이해하려면 “무엇을 잘하는 AI인가?”보다 “어떤 자료를 받아, 어떤 결과물을 만들고, 어디에서 사람이 확인하는가?”를 먼저 봐야 합니다. **『AI Agent를 지휘하는 마케터』는 리서치·전략 5개, 콘텐츠·크리에이티브 6개, 광고·CRM·성과분석 6개로 총 17개의 업무별 Agent를 다룹니다.**[1]

이 글은 박충효의 책에서 각 역할이 맡는 일을 짧게 정리한 독서 가이드입니다.[1] [2] 지금 막히는 업무에 가까운 역할을 고른 뒤, 책에서 입력 자료와 산출물, 검수 기준을 함께 확인해 보세요. 17개를 한꺼번에 구축해야 한다는 뜻은 아닙니다.

## Part 4. 리서치·전략 Agent: 시장과 고객을 읽는 다섯 역할

이 파트는 자료를 많이 모으는 것보다 캠페인 판단에 필요한 근거를 정리하는 데 초점을 둡니다. 시장·고객·경쟁사를 읽고, 페르소나와 캠페인 전략으로 연결하는 흐름입니다.[1]

### 1. 시장 트렌드 스캐너 Agent

시장의 화제와 고객 행동 변화를 브랜드에 의미 있는 신호로 걸러냅니다. **책에서 확인할 것:** 출처·영향·우선순위를 함께 정리하고, 일시적인 유행과 검토할 기회를 구분하는 기준입니다.

### 2. 고객 인사이트 Agent

리뷰와 고객의 소리에서 불만, 구매 장벽, 비교 기준을 찾아 메시지의 재료로 바꿉니다. **책에서 확인할 것:** 비식별 고객 자료를 분류하는 관점과 소수 의견을 전체 고객의 생각으로 일반화하지 않는 검수 기준입니다.

### 3. 경쟁사 분석 Agent

경쟁사의 메시지, 오퍼, 증거와 구매 흐름을 같은 기준으로 비교해 차별화의 여지를 찾습니다. **책에서 확인할 것:** 공개 자료로 비교표를 만들고, 알 수 없는 매출·전환 성과를 추정하지 않는 방법입니다.

### 4. 페르소나와 구매 여정 Agent

고객을 나이·직업만으로 묶지 않고 문제 상황과 구매 단계별 질문으로 이해합니다. **책에서 확인할 것:** 승인된 리서치로 고객의 질문, 필요한 콘텐츠와 CTA를 연결하고 가설을 갱신하는 흐름입니다.

### 5. 캠페인 전략 Agent

리서치 결과를 목표, 메시지, 오퍼, 채널과 성과 지표가 연결된 전략 브리프 초안으로 묶습니다. **책에서 확인할 것:** 승인된 자료를 다음 단계에 넘기는 방식과 예산·일정·리소스를 사람이 확정하는 지점입니다.

## Part 5. 콘텐츠 기획·카피·SEO: 내 업무에 적용해 보기

같은 브랜드 자료라도 콘텐츠 기획, 문안 작성과 검색 콘텐츠는 필요한 결과물이 다릅니다. 책은 역할을 구분해 기획의 방향을 확인한 뒤 제작으로 넘기도록 설명합니다.[1]

### 6. 콘텐츠 기획 Agent

캠페인 전략을 주차별 주제, 채널 역할, CTA와 제작 우선순위로 바꿉니다. **책에서 확인할 것:** 고객 여정과 브랜드 보이스를 반영한 콘텐츠 캘린더, 채널 중복과 무리한 발행량을 점검하는 기준입니다.

### 7. 카피라이팅 Agent

고객 언어와 브랜드 톤에 맞춰 후킹, 본문, CTA의 후보를 여러 방향으로 제안합니다. **책에서 확인할 것:** 문안의 의도와 적합한 채널을 함께 살피고, 과장 표현과 실제 오퍼의 불일치를 걸러내는 기준입니다.

### 8. SEO 콘텐츠 Agent

키워드 뒤의 검색 의도와 독자 질문을 읽어 글의 구조와 초안을 준비합니다. **책에서 확인할 것:** 목차·근거·FAQ·내부 링크·CTA를 먼저 설계하는 아웃라인과, 방향을 승인한 뒤 본문을 작성하는 순서입니다.

## Part 5. 랜딩·크리에이티브·QA: 제작을 마무리하는 역할

앞에서 정한 메시지는 페이지와 이미지·영상에서도 일관되어야 합니다. 마지막에는 잘 썼는지뿐 아니라 실제로 사용할 수 있는지를 별도로 확인합니다.

### 9. 랜딩페이지 Agent

고객의 구매 장벽을 기준으로 페이지의 섹션, 증거, FAQ와 CTA 흐름을 설계합니다. **책에서 확인할 것:** 섹션별 목적과 필요한 자료를 정리하고, 가격·혜택·후기·개인정보 안내와 링크 작동을 확인하는 기준입니다.

### 10. 숏폼·이미지·영상 크리에이티브 Agent

캠페인 메시지를 콘셉트, 장면, 스크립트와 자막 아이디어로 바꿉니다. **책에서 확인할 것:** 핵심 메시지는 유지하면서 표현을 변주하는 방법과 저작권·초상권·과장 연출을 검수하는 항목입니다.

### 11. 콘텐츠 QA Agent

만들어진 초안을 전략, 브랜드 보이스, 사실과 리스크 기준으로 점검합니다. QA는 품질 검수를 뜻합니다. **책에서 확인할 것:** 문제의 위험도와 수정 이유를 남기고, 불확실한 내용은 보류하거나 사람 확인으로 넘기는 방식입니다. AI의 점검은 최종 발행 승인을 대신하지 않습니다.

## Part 6. 광고·CRM·성과분석 Agent: 운영하고 개선하는 여섯 역할

이 파트의 Agent는 광고를 대신 집행하거나 숫자만 요약하는 역할에 머물지 않습니다. 다음 실험과 의사결정을 위한 자료를 구조화하고 기록을 남기는 흐름을 다룹니다.[1]

### 12. 퍼포먼스 광고 Agent

광고 목표와 성과 자료를 바탕으로 문제, 가설과 다음 실험안을 정리합니다. **책에서 확인할 것:** 한 번에 바꿀 변수, 성공·중단 기준과 예산 변경 전에 사람이 검토할 항목입니다. 자동 예산 집행을 뜻하지 않습니다.

### 13. 광고 소재 분석 Agent

소재의 성과와 후킹·비주얼·오퍼·CTA·랜딩 연결을 함께 읽어 테스트할 패턴을 찾습니다. **책에서 확인할 것:** 성과 차이를 비교하는 구성과 표본·타깃·게재 조건을 확인해 인과관계를 섣불리 단정하지 않는 기준입니다.

### 14. CRM·이메일 Agent

고객 관계 관리인 CRM에서 고객 상태와 행동 조건에 맞는 메시지 시나리오를 설계합니다. **책에서 확인할 것:** 발송 시점, 메시지 목적, 제외 조건과 빈도를 정리하고 수신 동의·개인정보·발송 피로도를 확인하는 방법입니다. 최종 발송은 사람의 승인이 필요합니다.

### 15. 데이터 리포팅 Agent

숫자 목록을 핵심 변화, 원인 가설, 다음 행동과 결정할 안건으로 바꿉니다. **책에서 확인할 것:** 보고서를 읽는 사람에 맞춘 요약과 지표 정의·비교 기간·추적 오류·표본 부족을 함께 표시하는 기준입니다.

### 16. 실험 관리 Agent

실험 전에는 가설과 조건을 정리하고, 실험 후에는 결과와 한계, 다음 시험을 기록합니다. **책에서 확인할 것:** 실험 ID·변수·통제 조건·성공 및 중단 기준을 같은 형식으로 남겨 재사용하는 방법입니다.

### 17. 마케팅 회의 Agent

회의 전에는 안건과 사전 자료를 정리하고, 회의 후에는 결정과 액션 아이템을 구조화합니다. **책에서 확인할 것:** 결정·보류를 구분하고 담당자, 마감일과 산출물을 남겨 다음 회의에서 확인하는 흐름입니다.

## 책을 읽으며 무엇을 확인하면 좋을까요?

역할을 골랐다면 해당 장에서 세 가지를 찾아보세요. **준비할 입력 자료, 다음 담당자가 사용할 결과물, 사람이 확인할 기준**입니다. 이 세 가지가 연결되어야 “AI에게 해 달라고 요청하는 일”이 실제 업무 지시로 구체화됩니다.

콘텐츠 업무가 막힌다면 Part 5에서 기획·카피·SEO의 차이를 먼저 읽어보세요. 광고와 CRM을 개선하고 싶다면 Part 6에서 실험·리포트·회의가 어떻게 이어지는지 확인할 수 있습니다. 시장이나 고객을 이해하는 근거가 부족하다면 Part 4부터 살피는 편이 좋습니다.

역할을 업무에 붙이는 공통 구조는 Part 3의 **R-G-C-T-O-R**에서 확인하세요. Role·Goal·Context·Tool·Output·Review, 즉 역할·목표·맥락·도구·산출물·검수로 지시를 정리하는 방식입니다. 데이터와 승인 기준은 Part 2, 반복 훈련과 운영 기록은 Part 7에서 함께 읽으면 됩니다.[1]

위 순서는 독자가 필요한 장을 찾도록 제안한 편집 읽기 안내입니다. 전체 구성은 [책 목차](/#contents), 지시서의 기본은 [책 소개 2](/blog/book-command-marketer-02), 한 업무에 적용하는 방법은 [책 실무 활용 가이드](/blog/command-marketing-book-practical-guide)로 이어서 확인할 수 있습니다.

## 자주 묻는 질문

### 책에는 업무별 AI Agent가 몇 가지 나오나요?

Part 4의 리서치·전략 5개, Part 5의 콘텐츠·크리에이티브 6개, Part 6의 광고·CRM·성과분석 6개로 총 17개입니다. 이 숫자는 해당 파트의 업무별 장 구성이지, 반드시 설치해야 할 프로그램 수가 아닙니다.

### 책을 읽으면 17개 Agent가 바로 자동 실행되나요?

아닙니다. 역할과 지시서·산출물·검수 구조를 이해하는 것과 실제 도구 연결·접근 권한·자동 실행을 구성하는 것은 다릅니다. 자신의 업무와 허용된 환경에 맞게 적용해야 합니다.

### 어떤 역할부터 읽는 것이 좋을까요?

지금 반복하거나 막히는 업무에 가까운 역할 하나부터 고르세요. 해당 장의 입력과 결과물을 읽고, Part 2·3의 데이터·승인 기준과 지시서 구조를 함께 확인하는 방식으로 시작할 수 있습니다.

### 콘텐츠 QA나 리포팅을 Agent에게 맡기면 최종 판단도 맡겨도 되나요?

아닙니다. 사실 확인, 브랜드·개인정보·광고 표현, 예산·발송과 결과 해석의 최종 책임은 사람에게 남습니다. Agent의 제안과 사람이 승인한 결정을 구분해야 합니다.

## 도서 소개와 편집 안내

이 글은 『AI Agent를 지휘하는 마케터』의 업무별 역할과 해당 장의 주제를 짧게 재서술한 **Command Marketing 도서 독서 가이드**입니다. AI 초안을 활용했으며 저자가 직접 집필한 블로그 글은 아닙니다. 읽기 순서와 질문은 편집 안내이고, 도서 전체나 각 장의 지시서·검수표를 대체하지 않습니다. 무인 자동 실행이나 업무·매출 성과를 보장하지 않습니다.
