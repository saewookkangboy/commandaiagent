# GEO 콘텐츠 발행 전 검수표

마케터·콘텐츠 담당자가 GEO(생성형 검색 환경을 고려한 콘텐츠 운영) 초안이나 대행 산출물을 검토할 때 쓰는 간단한 확인표입니다. GEO는 단일한 공식 서비스 규격이나 고정된 검색 순위가 아니므로, 제공 범위와 근거를 항목별로 확인하세요.

## 1. 독자 질문과 작업 범위

- [ ] 이 콘텐츠가 답할 대표 질문과 대상 독자를 한 문장으로 적었다.
- [ ] SEO 기본 작업(접근·색인·페이지 구조·검색 의도)과 생성형 답변 맥락을 고려한 편집 작업을 구분했다.
- [ ] AI 답변에 인용되거나 특정 순위에 오르는 것을 약속하는 문구를 넣지 않았다.
- [ ] 초안 작성, 사실 검증, 최종 승인, CMS 배포의 담당자가 각각 분명하다.

## 2. 내용·출처·기술 검수

- [ ] 핵심 답이 도입부와 소제목에 명확하고, 범위·조건·기준일·예외를 확인할 수 있다.
- [ ] 사실·수치·정책은 원출처와 대조했고, 출처가 불명확한 주장은 보류하거나 ‘확인 필요’로 표시했다.
- [ ] 공개해도 되는 자료만 사용했고, 개인정보·고객 자료·회사 기밀·저작권 범위를 확인했다.
- [ ] 중요한 본문이 초기 HTML에서 읽히며, 정규 URL·내부 링크·robots 접근·색인 상태를 점검했다.
- [ ] 구조화 데이터나 `llms.txt` 같은 파일을 AI 인용·순위의 보장 수단으로 설명하지 않았다.
- [ ] 생성형 AI 초안 여부, 편집·검토 책임과 공개 범위가 독자에게 오해 없이 표시된다.

## 3. 서비스·대행 결과물 인수인계

- [ ] 계약·작업 범위에 포함된 페이지, 산출물, 수정 횟수, 승인 단계와 제외 항목을 서면으로 확인했다.
- [ ] 질문·대상 URL·사용한 출처와 확인일·초안 버전·검수 상태·수정 이력을 전달받았다.
- [ ] 검색 성과 보고서가 노출·클릭·AI 답변 표본·웹 분석 전환을 구분하고 각 지표의 분모·기간·도구를 설명한다.
- [ ] 도구가 보여주는 ‘순위’나 인용 수가 어떤 서비스·지역·질문·시점·표본을 뜻하는지 확인했다.
- [ ] 내부 담당자, 다음 사실 확인일 또는 변경 시 재검수 조건을 정했다.

## 4. 발행 후 관찰과 다음 결정

- [ ] Search Console에서 정규 URL과 실제 검색어를 확인하고, 일반 웹 검색 지표와 Google 생성형 AI 기능 보고서를 구분한다.
- [ ] 노출은 클릭·세션·문의·매출과 다른 지표로 기록한다. AI 답변의 브랜드 언급과 클릭 가능한 출처 링크도 따로 본다.
- [ ] AI 답변은 고정한 질문·서비스·지역·기기·날짜로 표본 기록하고, 모든 이용자의 결과를 대표한다고 주장하지 않는다.
- [ ] 낮은 노출이나 두 자릿수 노출·0클릭 같은 작은 관측만으로 성공·실패 또는 인과 효과를 단정하지 않고 ‘판단 보류’ 가능성을 남긴다.
- [ ] 제목·본문·기술 설정을 한꺼번에 바꾸지 않고, 바꾼 항목과 비교 기간·외부 변수를 기록한다.
