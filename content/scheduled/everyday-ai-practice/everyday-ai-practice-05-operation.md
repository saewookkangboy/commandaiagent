# 검수한 프롬프트 v2, 계속 쓸까? 개인 업무 운영 카드 만들기

괜찮은 결과를 한 번 받았다고 해서 다음에도 같은 품질로 쓸 수 있는 것은 아닙니다. 어떤 자료를 넣었는지, 어떤 버전의 프롬프트를 사용했는지, 무엇을 사람이 확인했는지 기록해 두어야 다음 실행에서 다시 점검할 수 있습니다.

이 마지막 편에서는 4편의 v2와 테스트·변경 기록을 개인 업무 운영 카드 한 장으로 묶습니다. 재사용은 AI가 지난번의 검수 내용을 기억하거나 자동으로 학습했다는 뜻이 아닙니다. 기록과 판단은 사람이 관리합니다. 이 글은 예약·연동·상시 자율 실행을 설정하는 안내도 아닙니다.

## 입력·지시·검수·변경 기록을 한곳에 두기

운영 카드에는 결과를 다시 만들 때 필요한 최소한의 정보를 모읍니다. 허용되는 입력 형태, 현재 사용하는 프롬프트 버전, 사람이 확인할 항목, 지난 테스트에서 발견한 한계, 수정 이력을 함께 보관하세요.

```text
[개인 업무 운영 카드]
업무와 목적:
허용 입력 자료와 입력 양식:
검수한 프롬프트 버전:
사람이 확인할 기준:
테스트 기록과 변경 이력:
근거 오류·누락·미확인 항목:
사람 확인 또는 중단 조건:
결정: 유지 / 수정 후 재검증 / 중단
결정 이유와 다음에 확인할 것:
```

주간 메모 사례를 적용한다면 A는 읽고 메모한 자료, 다시 찾은 기록이 있는 자료로 보관할 수 있습니다. B는 제목만 기록되어 본문을 확인하지 못했고, C는 중간까지만 읽었습니다. 미제공된 내용이나 일정은 확인 불가로 유지합니다. 실제 4편 테스트 기록을 갖고 있지 않다면 결과를 꾸며내지 말고 해당 칸을 비워 두세요.

## 한 번 잘된 결과가 아니라 다시 쓸 조건을 정하기

카드에는 무엇이 입력으로 들어와야 하는지, 어떤 경우에는 결과를 승인하지 말아야 하는지도 적습니다. 예를 들어 메모의 출처가 불분명하거나 자료에 민감한 내용이 섞여 있으면 입력하지 않습니다. 분류의 근거가 빠졌거나 기록에 모순이 있으면 다음 실행으로 넘어가기 전에 사람에게 확인을 요청합니다.

다음에 같은 종류의 업무를 처리할 때는 프롬프트와 입력 조건이 크게 달라지지 않았는지 먼저 살핍니다. 이전 테스트와 다른 종류의 자료가 들어왔거나 맡기는 범위가 바뀌었다면, 과거의 검수 결과를 그대로 적용하지 않습니다. 다시 작은 표본으로 확인하거나 v2를 수정한 뒤 검증합니다.

실습은 먼저 수동으로 반복합니다. 매번 사람이 자료를 넣고 결과를 원문과 대조하는 방식입니다. 도구가 기록을 보존하거나 프롬프트 버전을 자동으로 기억한다고 가정하지 말고, 필요한 기록을 본인이 안전하게 관리하세요.

> 운영 원칙을 더 넓게 공부하고 싶다면 『AI Agent를 지휘하는 마케터』의 운영 점검 맥락과 [공식 도서 구성](https://book.allrounder.im/)을 살펴볼 수 있습니다. 책은 마케팅 실무서이며, 여기의 개인 운영 카드는 책의 원문 템플릿을 복제한 자료가 아니라 일반 독자용 편집 응용입니다 [1].

## 준비부터 검수·수정까지 전체 부담 살펴보기

AI가 초안을 빨리 만들었다고 해서 전체 일이 반드시 줄었다고 결론 내릴 수는 없습니다. 자료 준비, 실행, 검수, 수정까지 모두 살펴야 합니다. 각 단계가 실제로 측정되지 않았다면 ‘미측정’이라고 표시합니다.

```text
준비 시간: ____  (미측정 가능)
실행 시간: ____  (미측정 가능)
검수 시간: ____  (미측정 가능)
수정 시간: ____  (미측정 가능)
총 작업 시간: ____  (측정값이 없으면 미측정)
근거 오류·누락 또는 사람이 고친 부분:
```

AI를 쓰지 않았을 때와 비교하고 싶다면, 비슷한 양과 난이도의 자료를 같은 기준으로 관찰하세요. 품질, 누락, 수정 부담도 함께 기록합니다. 한 번의 비교나 초안 생성 시간만으로 일반적인 시간 절감 효과를 주장하지 않습니다. 이 글은 실제 시간 측정이나 성과를 제공하지 않습니다.

## 유지·수정 후 재검증·중단을 선택하기

기록을 확인한 뒤 지금 업무에 계속 도움이 되는지 결정합니다.

- **유지:** 현재 입력과 목적이 그대로이고, 사람이 확인할 수 있으며, 결과가 정해 둔 경계 안에 있음.
- **수정 후 재검증:** 입력 형식이나 업무 범위가 달라졌거나, 반복되는 누락·혼란이 확인되어 지시문을 고칠 필요가 있음.
- **중단:** 결과의 근거를 확인하기 어렵거나, 자료 권한이 불분명하거나, 검수 부담이 목적에 맞지 않음.

각각의 선택은 모두 유효한 결론입니다. 업무 범위를 줄이거나 체크리스트, 한 번의 Chat AI 요청으로 되돌아가는 것도 선택지입니다. 사용 횟수 자체가 유지해야 할 이유는 아닙니다.

이 시리즈에서 다룬 흐름은 업무 관찰 → 목표·경계 카드 → 프롬프트 v1 → 작은 시험과 v2 → 재사용 운영 카드입니다. 이 단계들은 학습 순서이지 며칠 안에 자동화가 완성된다는 약속이 아닙니다. 예약·외부 도구 연동·상시 실행을 원한다면 별도의 환경, 권한, 오류 처리, 사람의 중단 방법을 검토해야 합니다.

기존 글 [AI Agent에 무엇을 왜 맡길지 판단하는 안내](/blog/everyday-ai-agent-purpose)는 업무 후보를 고르는 배경을 다루며, 이 편은 검수한 지시문을 기록하고 운영 판단을 남기는 방법에 집중합니다 [2].

## 자주 묻는 질문

### 프롬프트를 다시 쓰면 AI가 지난번 검수 내용을 기억하나요?

그렇지 않습니다. 입력 양식, 검수 기준, 프롬프트 버전과 변경 기록을 사람이 관리해야 합니다. 사용하는 서비스의 기억 기능을 당연하다고 가정하지 말고 실제 설정과 데이터 처리 방식을 별도로 확인하세요.

### 운영 카드를 만들면 바로 예약하거나 상시 실행해도 되나요?

아닙니다. 이 실습은 사람이 직접 입력하고 검수하는 반복 운영부터 다룹니다. 예약·연동·자율 실행에는 도구 권한, 오류 처리, 기록 보관과 중단 장치에 대한 별도 검토가 필요합니다.

## 시리즈를 마치며

한 가지 업무를 관찰하고, 목적과 경계를 정하고, 프롬프트를 시험한 뒤 기록으로 남겼다면 작은 재사용 자산이 만들어진 것입니다. 다음 결정은 항상 자동화를 늘리는 것이 아니라, 현재 방식이 목적에 맞는지 다시 확인하는 일입니다.
